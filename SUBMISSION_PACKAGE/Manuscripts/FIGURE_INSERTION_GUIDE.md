# Figure Insertion Guide

Use only the `_FINAL.png` files in `SUBMISSION_PACKAGE/Figures/`. The current clean and highlighted DOCX files already contain the corrected `_FINAL.png` images for Figures 3-7. Manual replacement is not required unless Microsoft Word displays a problem or you intentionally want to reinsert the images.

If reinserting manually, place each image immediately above its existing caption and keep the figure number and caption together.
